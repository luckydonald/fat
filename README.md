# fat
So there's a `slim` docker image.
But what if you want the most battery-included image with all possible packages already installed? Well, now there's `fat`  (imagine sparkle emojis here).

Based on the wonderful https://www.naff.dev/blog/all-the-packages and the accompanying code at https://gist.github.com/chamlis/4d7441967787dc862f635a53958cabd6 (MIT).
